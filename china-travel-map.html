使用说明
  1. 建分类：点右上「＋ 新分类」，输入名称（名山、名河、古桥、古镇、园林…），再挑 emoji、主题色和地图图标样式（山峰 / 水波 / 古桥 / 屋舍 / 树木 / 楼塔 / 星形 / 旗帜 / 圆点 / 菱形 / 心形，共 12 种），随时可增改删。
  2. 录景点：点「＋ 新景点」→ 选分类 → 填名称 → 点「🔍 按名称自动定位」自动取坐标（也可手填经纬度）→ 写详细介绍 → 保存，点位立刻出现在地图上。
  3. 看点位：点击左侧分类，地图只显示该类别的点位并自动缩放到合适视野；清单同步过滤。开启「多选叠加模式」可同时看若干个分类。
  4. 看详情：点地图上的彩色图钉 → 弹出信息窗；点「查看详情」或左侧列表项 → 右侧抽屉展示完整介绍。
  5. 注册 / 登录：点右上「👤 登录 / 注册」创建账号。账号只存在本机浏览器，离线可用；每个账号的数据相互独立，登录自己的账号就只看到自己的分类与景点。不登录也能用，数据归「游客」。
  6. 备份与恢复：登录后点「👤 你的名字」→「创建备份点」，会保存最近 8 次快照，随时一键回滚；要换电脑或长期保存，用「导出 JSON」存文件，再到另一台机器「导入数据」。云同步未开启，数据不上传服务器。
  7. 数据保存：所有内容存在本机浏览器 localStorage，可随时「导出数据」备份成 JSON 或「导入数据」恢复。
  8. 换底图：地图右上角可切换「地形晕渲图 / 标准矢量图 / 卫星影像图」。地形晕渲由国家测绘局天地图提供，需免费申请 Key 后点「地形图密钥」填入；未填时自动回退为卫星影像。
  9. 加不上的排查：录入景点时若没填经纬度，保存会自动按名称定位；定位失败可点「📌 在地图上取点」，在地图上点一下即可自动填坐标。

地图服务：腾讯位置服务（符合国内地图合规要求）。快捷键：Esc 关闭弹窗/抽屉。
